Step through what each kind of layer actually computes, one number at a time.

Convolution

A convolutional layer slides a small grid of weights, the kernel (or filter), across the image. At each position it multiplies the kernel by the pixels underneath, adds the products up, and writes that single number into the output, called a feature map. Different kernels light up for different patterns: vertical edges, horizontal edges, outlines. In a real CNN the kernel values aren't hand-picked like these; they're learned during training.
