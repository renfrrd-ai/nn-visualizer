How neural networks compute

Every layer in a neural network is arithmetic: multiply, add, squash. This page lets you watch that arithmetic happen one number at a time, starting from a single artificial neuron and ending with the mechanism inside large language models.

Renfred Alonge, November 2026

1The perceptron

Every network on this page is built from one small part: the artificial neuron. The oldest and simplest version is the perceptron, introduced by Frank Rosenblatt in 1958. It takes a few numbers in, gives one number out, and has only three kinds of parts.

Each input x is multiplied by a weight w, which says how much that input matters and in which direction. The products are added together with a bias b, which sets how easily the neuron fires. That total is the weighted sum z. An activation function then turns z into the output ŷ. The perceptron's activation is a step: output 1 if z is at least zero, otherwise 0.

z = w1x1 + w2x2 + b,    ŷ = step(z)

Nobody sets the weights by hand. A perceptron learns them from labelled examples: points whose correct answer, the label y, is known. The perceptron learning rule is simple. Show it an example. If the output is right, change nothing. If it's wrong, nudge every weight towards the right answer:

w ← w + η (y − ŷ) x,    b ← b + η (y − ŷ)

The learning rate η sets the size of each nudge. One pass through every example is an epoch. Geometrically, the neuron splits the plane with a straight line, its decision boundary w1x1 + w2x2 + b = 0. Learning means moving that line until every point is on its correct side.

If a straight line can separate the two classes, the data is linearly separable, and the perceptron is guaranteed to find such a line. XOR isn't. No single line puts (0, 1) and (1, 0) on one side and (0, 0) and (1, 1) on the other. Minsky and Papert made this limit famous in 1969, and it stalled the field for years.

The fix is more neurons. Two neurons each draw their own line, and a third combines their answers. The two middle neurons form a hidden layer: they are neither input nor output. With a hidden layer, a perceptron becomes a neural network.

Modern networks make one more change: they replace the step with a smooth activation such as sigmoid or ReLU (try both in Figure 1). With a step, a small change in a weight either does nothing or flips the output. With a smooth function, every small change makes a small difference to the output. That is what lets backpropagation work out how to adjust every weight in a network with many layers at once.

The terms introduced here are used throughout the rest of the page:

Neuron (unit)
Computes a weighted sum of its inputs plus a bias, then applies an activation function.
Input x
A number fed into a neuron: a pixel, a feature, or another neuron's output.
Weight w
How strongly, and in which direction, an input pushes the neuron. Learned during training.
Bias b
A number added to the sum, shifting how easily the neuron fires. Also learned.
Parameters
All the weights and biases together: everything training adjusts.
Weighted sum z
The total w·x + b, before the activation. Also called the pre-activation.
Activation function
Turns z into the output: step, sigmoid, tanh, ReLU. The bend it adds is what lets stacked layers learn curved boundaries.
Output ŷ
The neuron's or network's prediction.
Label y
The correct answer for an example, used to measure mistakes.
Layer
A group of neurons that all read the same inputs. The input layer holds the data, hidden layers sit in the middle, and the output layer gives the answer.
Dense (fully connected)
A layer where every neuron reads every output of the layer before.
Training
Adjusting the parameters so the outputs match the labels.
Loss (error)
A number measuring how wrong the predictions are. Training tries to make it small.
Learning rate η
The size of each adjustment. Too small learns slowly; too large overshoots.
Epoch
One full pass through all the training examples.
Decision boundary
Where the network's answer changes from one class to the other. For a single neuron, a straight line.
Linearly separable
Data that one straight line (or flat plane) can split perfectly.
Backpropagation
The method for working out how much each weight in a multi-layer network contributed to the error, so each can be adjusted.

2Dense networks

Figure 3 needed a hidden layer of two neurons. Make the layers wider, stack more of them, and swap the step for a smooth activation, and you have a dense, or fully connected, network: the plain neural network. Every neuron reads every output of the layer before it, exactly like the perceptron:

z = w1a1 + w2a2 + … + b,    a = f(z)

The weighted sum z goes through an activation function f, which bends the line. Without that bend, stacking layers would collapse into one big linear function. The images, sequences and text in the chapters that follow all end up flowing through layers like this; CNNs, for example, usually finish with a few dense layers.

3Convolution

A convolutional layer slides a small grid of weights, the kernel, across an image. At each position it multiplies every weight by the pixel underneath, adds up the nine products, and writes that one number into a new grid called a feature map.

The kernel's numbers decide what it notices. A kernel with negatives on the left and positives on the right gives a large output only where the image gets brighter from left to right, so it finds vertical edges. In a trained network nobody writes these numbers by hand; they're learned.

The same nine weights work on a real photograph. The only difference is scale: a 160×160 image means 25,600 positions instead of 64. A colour photo also has three numbers per pixel, red, green and blue, so the filter first mixes them using its channel weights. Grayscale filters mix them as brightness (0.30, 0.59, 0.11); the colour filters pick out one colour against the others. Real CNNs learn a separate 3×3 kernel for each channel; mixing first keeps the arithmetic readable.

4Pooling

A feature map is as large as the image it came from. Pooling shrinks it. A window slides over the map and keeps one number per window, either the largest (max pooling) or the average. Nothing is learned here; there are no weights.

Shrinking is useful. Later layers have fewer numbers to process, and a feature that shifts by a pixel usually stays in the same window, so the network cares less about exactly where something is.

5Recurrent networks

Every network so far sees its whole input at once. Text, speech and time series arrive in order, so a recurrent network reads one item at a time and keeps a small vector h, the hidden state, that carries what it has seen so far:

ht = tanh( Wxhxt + Whhht−1 + b )

The same weights are used at every step. Drawing it "unrolled" makes it look like a chain of copies, but it is one network applied again and again.

6Attention

A recurrent network squeezes everything it has read into one small vector h, and by the end of a long sentence the early words have faded. Large language models like GPT drop the recurrence. Instead, every word is allowed to look directly at every other word and decide which ones matter to it. That mechanism is attention.

Each word's vector x is turned into three smaller vectors by three weight matrices:

q = xWQ,   k = xWK,   v = xWV

The query q says what a word is looking for. The key k says what a word offers. The value v is what it passes on if chosen. A word scores every other word by the dot product of its query with their keys, turns the scores into percentages with softmax, and takes that blend of their values as its new vector:

Attention(Q, K, V) = softmax( QK⊤ / √d ) V

Dividing by √d, the square root of the key length, keeps the scores from getting so large that softmax gives one word everything.

In a real model the embedding has thousands of numbers instead of six labelled ones, and all the weights are learned. Each layer runs dozens of heads side by side, then sends every word's result through a dense network like the one in chapter 2. Stack a few dozen of those layers and read off the last word's vector, and you get a prediction for the next word. Generate that word, append it, and repeat: that loop is a large language model.
